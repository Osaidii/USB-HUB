# USB-HUB
Welcome to a guide to make your own USB 2.0 HUB for less price and get the experience of making and DIY project.   
This product has a USB-A port to connect to the computer and 4 extra ports, 3 USB-A and one USB-C port.  
This guide and the files are open source and completely free to distribute, use, or modify but you are not allowed to sell these files. 
This USB HUB has a transfer rate of 480 Mbs (Megabits per second) or around 60 MBs (MegaBytes per second).  
This is alright for Keyboard, Mouse, Printer, USB Drives, Game Controllers, etc.   
This is not meant for use with High-Speed Devices, or Devices that require a lot of power like RGB-Heavy Devices or High-Power WIFI Adapters.
  
  
## Steps
This part of the guide will define an overview of the steps required to end up with a complete USB HUB.
1. Start by downloading the latest release of the files in this repository.
2. You will get the files Enclosure.obj, Project.epro, and Order.zip after you extract the files from the zip file.
3. This is the point where if you want to modify the project for yourself, you can do so by skipping ahead to ######### and coming back later.
4. Now we can start by placing our order of the PCB (Printed Circuit Board) and the 3D Printed Enclosure.
5. First of all you need to head to [JLCPCB](https://jlcpcb.com/) (which i am using) and create an account. You can also use any other PCB manufacturing service you want to use.
6. Then you need to press Order now and select Standard PCB/PCBA at the top.
7. After this, you will need to upload the Gerber files which is the Order.zip file we downloaded earlier.
8. The only settings we might need to change now are PCB Color and Surface Finish.
9. PCB Color is the color of the chip, in my opinion Green, Black, and Blue look good but you can choose whichever color you want (this only makes a visual difference).
10. For this PCB, you just need to confirm that the settings are set to 2 Layers and 1.6 mm PCB Thickness if not already selected.
11. For Surface Finish, you can select HASL with lead or Lead Free HASL (which I am going to be choosing since it is a little safer).
12. Then you need to scroll all the way down and turn on PCB Assembly and select 5 as PCB Assembly Quantity and then you can press next two times. 
13. Now you  would be able to see a table of items in front of you with weird names, you just need to make sure that all of the items are ticked on and turn them on if they are not.
14. Then you can go ahead and keep pressing next and finally press save to cart but do not order now.
15. Now we can go ahead and add our 3D Printed Enclosure in the same order since shipping is quite a lot on JLCPCB.
