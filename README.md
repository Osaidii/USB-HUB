# USB-HUB
Welccome to a guide to make your own USB 2.0 HUB for less price and get the experience of making and DIY project.   
This product has a USB-A port to connect to the computer and 4 extra ports, 3 USB-A and one USB-C port.  
This guide and the files are open source and completly free to distribute, use, or modify but you are not allowed to sell these files. 
This USB HUB has a transfer rate of 480 Mbs (Megabits per second) or arround 60 MBs (MegaBytes per second).  
This is alright for Keyboard, Mouse, Printer, USB Drives, Game Controllers, etc.   
This is not meant for use with High-Speed Devices, or Devices that require a lot of power like RGB-Heavy Devices or High-Power WIFI Adapters.
  
  
## Steps
This part of the guide will define a overview of the steps required to end up with a complete USB HUB.
1. Start by deciding if you want to modify the final product by changing the ports or adding more features. For this, please address.
2. After step 1, you need to start by placing an order on JLCPCB (i will be using this) or any other PCB manufacturing service.
3. You can go ahead and download the Manufacturing Release on this Repository.
4. First of all you need to head to [JLCPCB](https://jlcpcb.com/) and create an account.
5. Then you need to press Order now and select Standard PCB/PCBA at the top.
6. After this, you will need to upload the Gerber files which are inside the release that you downloaded earlier.
7. The only settings we might need to change now are PCB Color and Surface Finish.
8. PCB Color is the color of the chip, in my opinion Green, Black, and Blue look good cut you can choose whatever you want.
9. For this PCB, you need to select 2 Layers if it is not only selected and 1.6 mm PCB Thickness.
10. For Surface Finish, you can select HASL with lead or Lead Free HASL (which i am going to be choosing).
11. Then you need to scroll all the way down and turn on PCB Assembly and select 5 as PCBA Qty.
